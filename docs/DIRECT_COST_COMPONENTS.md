# Direct cost components

A calculation line can carry explicit direct costs in addition to material and labour:

- equipment;
- subcontract;
- other direct cost.

Components remain separate and keep a description and source reference. They are never hidden in a generic percentage.

The complete direct cost is material + labour + equipment + subcontract + other direct cost.

The Office handoff contract `brebo-calc-calculation-line-handoff-v3` exposes every component and totals per cost kind. Existing v1 and v2 contracts remain intact for compatibility.
