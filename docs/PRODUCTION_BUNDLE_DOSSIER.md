# Production bundle dossier

Scanning a production bundle opens a focused execution dossier.

The dossier contains:
- bundle identity and current status;
- destination;
- the pieces/components belonging to the bundle;
- references to relevant drawings, photos, instructions and Office documents.

## Boundary

Calc may keep the production snapshot needed to execute the released calculation, but it does not become the authoritative document store.

Documents, drawings, photos and project truth remain in Office. Bundle dossier links store external references and titles, not duplicate document binaries.

This gives the workshop and site a stable released production package while keeping Office authoritative for the underlying project dossier.

A later UI can present large execution actions such as:
- Start production
- Mark ready
- Block / report deviation
- Dispatch
- Confirm on site
- Complete

Those actions should be role-controlled and audited.
