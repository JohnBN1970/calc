# Production outputs

One approved set of cutting requirements produces role-specific outputs.

## Purchase list
Shows only stock lengths and quantities required for procurement.

## Workshop list
Shows only workshop-designated bundles and the piece lengths to cut. The list is grouped by installation destination and sorted for practical handling.

## Labels
Every workshop bundle receives a short destination label. Labels travel with the bundle to the project.

## Site list
Contains only pieces deliberately designated for site cutting/fitting. Workshop-ready pieces do not appear here.

The goal is that each role receives only the information needed to execute the work. Calculation logic and optimization details remain upstream.
